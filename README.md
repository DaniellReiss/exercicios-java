# Exercícios do Curso de Java Completo - Nélio Alves

Este repositório contém as minhas resoluções pessoais para os exercícios propostos no curso "Java COMPLETO Programação Orientada a Objetos +Projetos" do Professor Nélio Alves.

O objetivo deste portfólio é documentar o meu progresso, praticar os conceitos aprendidos em aula e demonstrar as minhas habilidades em desenvolvimento com a linguagem Java e com o Git e GitHub.

### Tecnologias Utilizadas
* Java
* IntelliJ IDEA
* Git & GitHub
* Maven

### Sobre o Curso
O curso foca em tópicos como Lógica de Programação, Programação Orientada a Objetos (POO), tratamento de exceções, manipulação de ficheiros, e muito mais. Ele pode ser encontrado em plataformas como a Udemy.
